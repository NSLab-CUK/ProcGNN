# MODEL 260729

## E2 Balanced-384 + Focus Sampler

이 문서는 2026-07-29에 확정한 화학공정 그래프 surrogate 모델의 구조와 학습 방법을 사람이 한 번에 이해할 수 있도록 정리한 문서다.

기준 설정 파일은 다음과 같다.

```text
configs/experiment/pinn/head_dimension_260729/
e2_balanced384_focus_sampler.yaml
```

핵심 설계는 다음 한 줄로 요약할 수 있다.

```text
공정 그래프
→ 5-layer Bidirectional FlowGNN
→ 384D node/edge/global representation
→ 1536D edge descriptor
→ E2 hierarchical reduced PI head
→ 11개 물성 직접 예측
```

학습에서는 전체 데이터 풀을 매 epoch 모두 사용하지 않는다.

```text
기존 분포를 보존하는 기본 표본 1,000개
+ Target CO hard sample 400개
+ Target Mass_Flow hard sample 400개
+ Target CH4 hard sample 200개
= epoch당 2,000개
```

## 1. 이 모델을 선택한 이유

차원 ablation에서 E1, E2, E5, E6를 비교한 결과는 다음과 같았다.

| 모델 | 파라미터 | Target aggregate R2 | All-edge 평균 R2 |
|---|---:|---:|---:|
| E1 | 32.73M | **0.87730** | 0.89193 |
| **E2** | **19.43M** | **0.87350** | **0.89320** |
| E5 | 8.65M | 0.87482 | 0.88852 |
| E6 | 34.50M | 0.86023 | 0.89372 |

E2는 E1보다 파라미터가 약 40.6% 적다. Target aggregate R2 차이는 약 0.0038에 불과하고, All-edge 평균 R2는 오히려 약 0.0013 높았다. 따라서 성능을 거의 유지하면서 학습 비용과 추론 비용을 크게 줄이는 균형점으로 E2를 선택했다.

E5는 더 작지만 All-edge H2O, Mass_Flow, Vol_Flow에서 표현력 한계가 보였다. E6는 더 큰데도 Target 성능이 낮아 파라미터 증가의 실익이 없었다.

Stream ID embedding은 유지한다. 이를 제거한 E4에서 Target CH4와 CO2가 크게 붕괴했다. 같은 두 node 사이를 잇는 평행 stream edge는 source/destination node만으로 구별하기 어려우므로, 32D Stream ID는 단순한 부가 정보가 아니라 평행 edge를 구분하는 식별 단서다.

## 3. 입력 표현을 이렇게 구성한 이유

### 3.1 Node role과 unit type

공정 graph에서 node는 단순한 위치가 아니다. mixer, separator, reactor 등 서로 다른 기능을 가진다. Node role과 unit type embedding은 같은 operating value라도 장치 기능에 따라 다르게 해석할 수 있게 한다.

### 3.2 Operating mask

운전변수의 0은 실제 물리값 0일 수도 있고, 값이 존재하지 않아 채운 0일 수도 있다. 13D mask를 함께 넣어 모델이 두 경우를 구분하게 한다. 이것은 결측값을 수치 0으로 오해하는 것을 줄인다.

### 3.3 Stream ID

평행 edge는 source node, destination node, 구조 속성이 같을 수 있다. Stream ID embedding이 없으면 서로 다른 product, recycle, purge stream을 동일한 edge로 취급할 위험이 있다. E4 ablation의 붕괴 결과 때문에 32D embedding을 유지한다.

### 3.4 Structural attributes

3개의 raw 구조 속성을 바로 큰 representation에 붙이지 않고 16D로 인코딩한다. 작은 구조 신호가 384D node feature에 묻히지 않게 하면서도 과도한 차원 증가는 피한다.

## 4. Bidirectional FlowGNN

### 4.1 왜 양방향인가

공정의 주된 정보 흐름은 inlet에서 outlet으로 진행하므로 forward message passing이 필요하다. 그러나 실제 공정에는 recycle, downstream constraint, pressure/flow coupling이 존재하므로 반대 방향 문맥도 필요하다.

각 layer는 두 방향을 별도로 집계한다.

```text
Forward:  source → destination
Backward: destination → source
```

두 결과를 concat한 뒤 384D로 fusion한다. 방향을 먼저 구분한 뒤 결합하므로, 처음부터 무방향 graph처럼 섞는 것보다 흐름 방향의 의미를 보존한다.

### 4.2 Attention

이웃 edge의 기여도를 동일하게 평균하지 않는다. sender hidden, receiver hidden, edge embedding을 함께 사용해 방향별 attention을 계산한다. 따라서 현재 node 상태와 stream 종류에 따라 중요한 유입/유출 stream에 더 큰 가중치를 줄 수 있다.

### 4.3 Layer residual

각 layer의 새 hidden을 그대로 덮어쓰지 않고 이전 hidden과 보간한다.

```text
h_interp = h_prev + 0.5 × (h_new - h_prev)
```

이는 다음과 같다.

```text
h_interp = 0.5 × h_prev + 0.5 × h_new
```

새 message와 기존 표현을 같은 비율로 섞어 깊은 message passing에서 표현이 갑자기 변하거나 불안정해지는 것을 줄인다.

### 4.4 Initial-state injection

각 layer 뒤에 최초 node representation을 다시 소량 주입한다.

```text
h_l = h_interp + 0.05 × h0
```

5개 layer를 통과하면서 모든 node가 비슷해지는 over-smoothing을 줄이고, 각 장치의 원래 role, unit type, operating condition을 마지막 layer까지 보존하려는 설계다.

Layer residual은 바로 전 layer를 보존하고, initial-state injection은 첫 입력을 반복해서 보존한다. 둘은 목적이 다르므로 함께 사용한다.

## 5. Global graph context와 edge descriptor

한 edge의 물성은 인접한 두 node만으로 결정되지 않는다. 전체 공정의 feed 조건, recycle 상태, 다른 unit의 운전조건에도 영향을 받는다. 따라서 Set2Set으로 모든 local node를 읽어 768D global representation을 만든다.

Set2Set의 768D를 그대로 쓰면 global feature가 local source/destination feature보다 두 배 큰 비중을 차지한다. 이를 384D로 투영해 네 요소를 같은 차원으로 맞춘다.

```text
source 384
+ destination 384
+ global 384
+ edge 384
= descriptor 1536
```

여기서 마지막 edge 384D는 raw structural 3D가 아니라 Stream role, Stream ID, structural attributes를 모두 인코딩한 GNN edge embedding이다.

## 6. Hierarchical Reduced PI Head

### 6.1 Shared decoder

1536D descriptor를 `1536 → 768 → 384`로 압축한다. 이 단계는 모든 물성이 공유하는 edge 상태를 학습한다.

LayerNorm은 sample마다 feature scale을 안정화하고, GELU는 부드러운 비선형성을 제공하며, dropout 0.1은 과적합을 줄인다. 입력과 출력 차원이 다르므로 shared decoder 자체의 residual은 사용하지 않는다.

### 6.2 물성별 branch

하나의 거대한 output layer가 모든 물성을 동시에 예측하면 scale과 난이도가 다른 물성이 서로 방해할 수 있다. 그래서 조건, 조성, 질량유량을 분리한다.

```text
Condition: 384 → 96 → Temp, Pres
Fraction:  384 → 128 → 7 fractions
Mass:      384 → 96 → Mass_Flow
```

Fraction branch는 다른 물성보다 조금 넓은 128D를 사용한다. 7개 성분의 상대적인 경쟁과 희소 성분을 동시에 표현해야 하기 때문이다.

### 6.3 Fraction softmax

7개 fraction logit `a_k`를 temperature 0.5의 softmax로 변환한다.

```text
x_k = exp(a_k / 0.5) / Σ_j exp(a_j / 0.5)
```

따라서 항상 다음 조건을 만족한다.

```text
x_k ≥ 0
Σ_k x_k = 1
```

별도 closure penalty를 추가하지 않아도 조성 합이 1이 된다. Temperature 0.5는 작은 성분 차이를 더 뚜렷하게 만들어 희소 성분의 구분력을 높인다.

### 6.4 Mass_Flow와 Vol_Flow 분리

Mass_Flow는 shared representation에서 직접 예측한다. Vol_Flow는 Temp, Pres, 조성, Mass_Flow가 결정된 뒤 Level-1 10D를 입력으로 예측한다.

```text
Level-1 = [Temp, Pres, 7 fractions, Mass_Flow]
Vol_Flow = f_volume(detach(Level-1))
```

`detach`를 사용한 이유는 불안정한 Vol_Flow gradient가 Temp, Pres, fraction, Mass_Flow branch를 역으로 흔드는 것을 막기 위해서다. Volume branch 자체는 학습되지만, volume loss가 Level-1 branch를 변경하지는 않는다.

### 6.5 Mole_Flow는 예측하지 않음

Mole_Flow는 head output, supervised loss, 최종 11D prediction에 포함하지 않는다.

Component/atom PINN은 질량 기준 값을 몰 및 원자 기준으로 변환해야 하므로, 물리 residual을 계산하는 내부에서만 다음 중간값을 사용할 수 있다.

```text
MW_mix = Σ_k x_hat_k MW_k
n_total_internal = Mass_Flow_hat / MW_mix
```

이 값은 물리 loss 계산용 중간 tensor일 뿐 Mole_Flow 예측값으로 저장하거나 평가하지 않는다.

## 7. Edge supervision

기본 supervised loss는 Smooth L1이다.

오차를 `d = y_hat - y`라 하면:

```text
SmoothL1(d) =
    0.5 d²             if |d| < 1
    |d| - 0.5          otherwise
```

MSE보다 큰 outlier에 덜 민감하면서, 작은 오차 구간에서는 부드러운 gradient를 제공한다.

Fraction에는 작은 실제값의 상대 오차를 무시하지 않도록 log-space 항을 추가한다.

```text
L_frac_log =
mean_k SmoothL1(
    log(x_hat_k + 1e-6),
    log(x_k + 1e-6)
)
```

현재 fraction log loss weight는 0.75다. CLR loss와 별도 closure loss는 사용하지 않는다. Closure는 softmax가 이미 보장하므로 중복 penalty를 제거한 것이다.

Mass_Flow는 큰 동적 범위를 다루기 위해 scaled-log 설정을 사용한다.

```text
z_m = 2 × log(1 + Mass_Flow / 1)
```

이 변환은 큰 유량 몇 개가 전체 loss를 지배하는 것을 줄인다.

Target edge weight는 5다. Target을 일반 edge와 똑같이 두면 수가 많은 non-target edge에 묻힐 수 있지만, 과거의 weight 40은 target gradient가 지나치게 지배할 위험이 있었다. 5는 target을 강조하되 전체 edge 표현을 훼손하지 않기 위한 절충값이다.

## 8. Sample-hybrid optimizer update

학습 batch size는 1 graph sample이다. 하나의 sample 안에서 edge 중요도에 따라 optimizer update를 분리한다.

```text
1. 모든 non-target edge loss를 macro mean
   → fresh forward
   → backward
   → optimizer.step 1회

2. 각 target edge를 하나씩
   → target마다 fresh forward
   → 개별 backward
   → optimizer.step 1회

3. Node PINN + supervised anchor
   → fresh forward
   → joint backward
   → optimizer.step 1회
```

Target edge가 3개인 sample의 정상 update 수는 다음과 같다.

```text
non-target 1 + target 3 + node 1 = 5 updates
```

Target을 개별 update하는 이유는 CH4, CO 같은 어려운 target의 gradient가 다른 edge 평균에 묻히지 않게 하기 위해서다. 각 update에서 fresh forward를 사용하므로 이전 optimizer step으로 parameter가 바뀐 뒤 오래된 autograd graph를 재사용하지 않는다.

## 9. Node PINN과 A2 supervised anchor

### 9.1 활성 PINN

현재 활성화된 node-level 물리 loss는 세 가지다.

```text
Mass balance
Component balance
Atom balance
```

Energy PINN은 비활성이다. 현재 head가 Enthalpy를 직접 예측하지 않고, 일부 ground-truth node가 energy balance 자체와 맞지 않는 문제가 확인됐기 때문이다. 불완전한 energy residual을 강제로 줄이면 Mass_Flow와 다른 물성이 함께 붕괴할 수 있다.

### 9.2 Mass balance

node `v`에서:

```text
R_mass(v) =
Σ_(e in In(v))  m_hat_e
- Σ_(e in Out(v)) m_hat_e
```

유입 질량유량과 유출 질량유량의 차이를 줄인다.

### 9.3 Component balance

성분 `k`의 질량 기준 유량은 다음과 같이 구성한다.

```text
m_hat_(e,k) = m_hat_e × x_hat_(e,k)
```

node별 component residual은:

```text
R_comp(v,k) =
Σ_(e in In(v))  m_hat_(e,k)
- Σ_(e in Out(v)) m_hat_(e,k)
```

### 9.4 Atom balance

성분별 몰유량과 원자 조성 행렬을 사용한다.

```text
n_hat_(e,k) = m_hat_(e,k) / MW_k
```

원소 `a`에 대해:

```text
F_hat_(e,a) = Σ_k A_(k,a) n_hat_(e,k)
```

따라서:

```text
R_atom(v,a) =
Σ_(e in In(v))  F_hat_(e,a)
- Σ_(e in Out(v)) F_hat_(e,a)
```

### 9.5 상대 residual과 robust loss

유량 규모가 큰 node만 loss를 지배하지 않도록 각 residual을 true-flow scale로 정규화한다.

```text
r_rel = R / max(S_true, 1.0, 1e-6)
r_safe = clip(r_rel, -10, 10)
```

그 뒤 Huber loss를 적용한다. 현재 delta는 0.5다.

```text
Huber_0.5(r) =
    0.5 r²                         if |r| ≤ 0.5
    0.5 × (|r| - 0.25)            otherwise
```

최종 node PI 항은:

```text
L_node =
0.75 × L_mass
+ 1.5e-7 × L_component
+ 0.2 × L_atom
```

Component residual은 수치 단위가 매우 커질 수 있어 작은 weight를 사용한다. 이 값은 중요도가 없다는 뜻이 아니라, 세 residual의 gradient scale을 맞추기 위한 단위 보정이다.

### 9.6 A2 joint supervised anchor

Node PINN step에서 물리 loss만 단독으로 최적화하지 않는다.

```text
L_node_update =
1.0 × L_supervised_anchor
+ 0.05 × s(epoch) × L_node
```

Anchor에는 target weight 5를 다시 적용하지 않는다. 이 step의 목적은 target을 한 번 더 강조하는 것이 아니라, PINN이 예측값을 데이터 manifold에서 멀리 밀어내지 못하게 붙잡는 것이다.

이 구조를 사용한 이유는 과거 node PINN 활성화 직후 Mass_Flow와 다른 supervised 성능이 무너지는 현상을 막기 위해서다. 물리 일관성을 개선하되 실제값 적합도를 동시에 보존한다.

### 9.7 PINN schedule

Node PINN multiplier `s(epoch)`는 다음과 같다.

| Epoch | Multiplier | 의미 |
|---|---:|---|
| 1-5 | 0.0 | supervised representation 먼저 형성 |
| 6-7 | 0.5 | PINN을 절반 강도로 도입 |
| 8 이후 | 1.0 | 설정된 PINN weight 전체 적용 |

학습 초기에 무작위 prediction으로 계산한 큰 물리 residual이 encoder와 head를 망가뜨리지 않도록 warm-up을 둔다.

## 10. Epoch sampling

전체 60% train pool에서 매 epoch 2,000개만 선택한다.

| 구성 | 개수 | 목적 |
|---|---:|---|
| 기본 분포 표본 | 1,000 | 전체 공정과 일반 물성 분포 보존 |
| Target Frac_CO hard | 400 | 가장 낮은 target 성능 보강 |
| Target Mass_Flow 일반 고유량 | 240 | 100k 이상 500k 미만 구간 회귀 보강 |
| Target Mass_Flow 극고유량 | 160 | 500k 이상 tail 과소예측 보강 |
| Target Frac_CH4 hard | 200 | CH4 target 성능 유지 및 보강 |
| Target Frac_CO2 hard | 0 | 이미 높은 성능이므로 추가 편향 방지 |
| **합계** | **2,000** | |

### 10.1 기본 1,000개

기본 표본은 단순 uniform 1,000개가 아니다. 다음 mixture를 유지한다.

| Bucket | 비율 |
|---|---:|
| Uniform | 25.0% |
| Sparse-positive fraction | 37.5% |
| Property quantile balance | 25.0% |
| Mass_Flow tail mixture | 12.5% |

또한 process balance와 epoch 내 중복 방지를 적용한다. 이 기본 절반이 있기 때문에 hard sample을 추가해도 전체 공정 분포와 일반 edge 성능을 잃지 않는다.

### 10.2 Hard 1,000개

Hard sample은 산출물에서 실제로 저조했던 target property와 canonical edge를 중심으로 고른다.

- CO 400: P03 dominant edge와 P05/P06/P10 support edge
- Mass_Flow 240: 100k 이상 500k 미만의 일반 고유량
- Mass_Flow 160: 500k 이상의 극고유량
- CH4 200: P06/P07/P08 target edge

Mass_Flow를 두 구간으로 나눈 이유는 극고유량 후보가 매우 많아 단일 `100k 이상` pool을 쓰면 500k 이상 sample이 400개 quota를 과도하게 점유할 수 있기 때문이다. 일반 고유량 60%, 극고유량 40%를 고정해 중간 고유량 회귀와 극단 tail 대응을 함께 유지한다. 두 구간은 겹치지 않으며, 각 구간 안에서는 P01/P04/P06/P09/P10 canonical target edge를 균형 있게 순회한다.

같은 sample은 한 epoch 안에서 한 번만 사용한다. 특정 hard pool이 부족하면 남는 수만큼 전체 train pool에서 중복 없는 random sample로 채운다. 따라서 hard 후보 부족으로 epoch 크기가 2,000보다 작아지지 않는다.

CO2 hard sample을 제거한 이유는 CO2가 이미 target과 all-edge에서 높은 성능을 보였기 때문이다. 이미 잘 되는 성분에 quota를 쓰면 CO, CH4, Mass_Flow 개선 기회를 줄이고 분포 편향만 키울 수 있다.

## 13. 정상 동작 확인 기준

Sampler 로그에서는 다음 값이 보여야 한다.

```text
base = 1000
hard = 1000
total = 2000
hard_property_counts:
  Frac_CO = 400
  Mass_Flow = 400
  Frac_CH4 = 200
hard_rule_counts:
  target_mass_flow_high = 240
  target_mass_flow_extreme = 160
```

`hard_property_shortfalls`와 `hard_rule_shortfalls`가 0이면 각 property와 Mass_Flow 구간 quota를 모두 채운 것이다. 값이 양수여도 부족분은 random fallback으로 채우므로 total은 2,000을 유지한다.

Target edge가 3개인 일반 sample의 학습 로그는 대체로 다음과 같아야 한다.

```text
updates = opt5 / target3 / non-target1 / node1
forward = 5
```

Epoch 1-5에서 node PINN weighted contribution이 0인 것은 schedule에 따른 정상 동작이다. Epoch 6-7에는 절반, epoch 8부터 전체 weight가 적용돼야 한다.

다음은 즉시 점검해야 할 이상 징후다.

- fraction 합이 1에서 벗어남
- epoch sample total이 2,000이 아님
- gradient norm이 반복적으로 clip 전 수백 이상으로 폭증
- non-finite loss 또는 optimizer step skip이 지속
- epoch 1-5에 node PINN이 실제 gradient에 반영됨
- best checkpoint의 Target CO, CH4, Mass_Flow가 수정 전보다 계속 악화됨

## 14. 최종 요약

MODEL 260729는 가장 큰 모델을 선택한 것이 아니라, 성능 대비 계산 효율이 가장 좋은 E2를 선택한 모델이다.

```text
19.43M parameter Balanced-384 body
+ 방향을 분리한 5-layer FlowGNN
+ layer residual과 initial-state injection
+ Stream ID를 포함한 parallel-edge 구분
+ local/global/edge 정보를 같은 384D로 정렬
+ 조건/조성/질량/체적을 분리한 hierarchical PI head
+ softmax 조성 closure
+ non-target 평균 + target 개별 update
+ A2 supervised anchor가 포함된 robust Node PINN
+ 1,000 base + 1,000 targeted hard sampling
```

설계의 중심 원칙은 세 가지다.

1. **표현력과 효율의 균형:** E1과 거의 같은 성능을 더 작은 E2로 달성한다.
2. **어려운 target을 직접 보강:** CO, Mass_Flow, CH4에 학습 기회를 집중하되 기본 1,000개로 전체 분포를 보존한다.
3. **물리 loss가 supervised prediction을 파괴하지 않게 함:** robust residual, gradient clipping, warm-up schedule, A2 supervised anchor를 함께 사용한다.
